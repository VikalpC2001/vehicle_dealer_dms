# RTO Super Admin — Design System

This Storybook is the **single source of truth** for all UI components and design tokens in the RTO Super Admin application.

## Design Philosophy

Enterprise SaaS admin panel inspired by Stripe, Linear, Notion, and Vercel.

- **Clean** — generous whitespace, clear hierarchy
- **Professional** — trustworthy, government-grade
- **Premium** — polished interactions, restrained shadows
- **Data-focused** — metrics and content first

## Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | React 19 + Vite |
| Styling | Tailwind CSS v4 |
| Components | ShadCN UI (Radix + CVA) |
| Icons | Lucide React |
| Animation | Framer Motion |
